## Komutlar

G03 zarfındaki environment=demo, exchange=binance, product=USD-M, context çıktısından account_ref ve benzersiz client_command_id korunur.

| operation | scope | parameters |
|---|---|---|
| CANCEL_SELECTED_ORDERS | symbol | targets: [{namespace: NORMAL veya ALGO, client_id: ...}], include_foreign: boolean |
| CANCEL_SYMBOL_ORDERS | symbol | include_foreign: boolean |
| CANCEL_ACCOUNT_ORDERS | account_wide: true | include_foreign: boolean |
| SET_CANCEL_TIMER | symbol | countdown_ms, heartbeat_ms, lease_ms, acknowledge_symbol_wide: true |
| REFRESH_CANCEL_TIMER | symbol | timer_id |
| DISABLE_CANCEL_TIMER | symbol | timer_id |
| QUERY_CANCEL_TIMER | symbol | timer_id |

Seçili/sembol/timer kullanıcı kapsamı mevcut USDT sembol doğrulamasını kullanır. Hesap kapsamı sembol takma adı değildir: aynı demo USD-M hesabında keşfedilen emirleri kapsar; başka ürünlere veya hesaplara yayılmaz. Tek iptal komutu en fazla 200 hedef alır; fazla hedef sessizce kesilmez, komut reddedilir. Büyük hesaplarda ayrı, incelenebilir komutlar gerekir.

```powershell
python -m agentrader commands context
python -m agentrader commands prepare cancel.json
python -m agentrader commands show COMMAND_ID
python -m agentrader commands apply COMMAND_ID --digest DIGEST --execute-demo
python -m agentrader commands reconcile COMMAND_ID
```

## Dondurulmuş iptal kapsamı

Prepare borsayı yalnız okur; kalıcı önizlemede broker kimliği, normal/algo ad alanı, sembol, emir özellikleri, sahiplik ve atlanan emirler bulunur. Bunlar digest'e bağlıdır. Aynı komut kimliğiyle tekrar prepare yeni emir eklemez. Apply önce bütün hedefleri yeniden doğrular; kimlik veya emir özellikleri değişmişse hiçbir DELETE göndermez. Geniş kapsamlar da bu sabit liste üzerinden tekil kimliklerle uygulanır. Önizlemeden sonra oluşan emirler kapsama girmez; geniş DELETE-all uçları kullanılmaz.

include_foreign=false yalnız sahipliği kalıcı plan/oturum/niyet kayıtlarıyla doğrulanan emirleri kapsar. İstemci kimliği öneki sahiplik kanıtı değildir. Seçili yabancı emir reddedilir; geniş kapsamda atlanır. include_foreign=true mevcut hesaptaki yabancı emirleri açıkça kapsama alır. Yönetilen çekirdek stop/hedef korumaları bu durumda da korunur: seçili komut reddedilir, geniş komutta CORE_PROTECTION_PRESERVED olarak gösterilir.

Sahip olunan giriş iptali entry_revoked kaydını aynı transaction içinde yazar; mevcut yöneticinin yeni giriş/GRID yeniden doldurması engellenir. İptal pozisyonu kapatmaz ve risk rezervini doğrudan serbest bırakmaz. Dolum yarışı gerçek dolum miktarıyla gösterilir. Her üyenin sonucu ayrı sorgulanır; tek başarılı cevap bütün grubu başarılı yapmaz. APPLIED, hedeflerin terminal olduğu anlamına gelir; hepsinin CANCELED veya hesabın pozisyonsuz olduğu anlamına gelmez.

Tetiklenen algo ile normal alt emir ayrı kimliklerdir. Terminal algo ana emri açık alt emrin bittiğini kanıtlamaz. Alt emir bilgisi sonuçta gösterilir; açık çocuk için yeni NORMAL seçim gerekir. Kapsam kendiliğinden genişletilmez.

DELETE öncesinde üye niyeti ve mevcut iptal yollarıyla ortak kimlik engelleri kalıcı yazılır. Kayıp cevap veya niyet sonrası kesinti tekrar gönderime yol açmaz; restart/reconcile yalnız sorgular. Kesin NOT_SENT sonucu aynı komutun tekrarını açmaz; yeni açık komutla yeniden denenebilir. Günlük digest bozulması yeni gönderimi engeller.

## Timer yetkisi ve heartbeat

Timer sembol çapında gelecekteki açık emirleri de etkileyebilen geniş bir borsa işlemidir. Kurma ve yenileme öncesinde sembolde yönetilen oturum, sıfırdan farklı pozisyon veya açık algo varsa reddedilir. Algo emirlerinin countdown dışında kaldığı varsayılmaz. Dış istemciler bu kontrollerden sonra hesabı değiştirebilir; bu bir hesap kilidi değildir.

SET örnek parametreleri: countdown_ms=6000, heartbeat_ms=1000, lease_ms=30000, acknowledge_symbol_wide=true. Heartbeat en az 1 saniye, en fazla 60 saniye ve countdown'un en fazla yarısıdır. Lease en fazla 10 dakikadır ve prepare anından başlar. Tekrarlanan komut lease'i uzatmaz. Aynı hesap/sembolde ikinci aktif veya belirsiz timer kurulmaz.

```powershell
python -m agentrader commands timer-run TIMER_ID --digest SET_COMMAND_DIGEST --execute-demo --iterations 0
```

Worker ayrıca açıkça başlatılır; uygulama restart olduğunda otomatik başlamaz. iterations=0 yalnız ilk yetkinin sabit lease sonuna kadar çalışır. Kilit uyku sırasında bırakılır. Her heartbeat ayrı sıra ve sonuçla günlüktedir. Süre geçmişse yeniden kurmaz; lease dolunca yenilemeyi bırakır. Kayıp cevap, başarısız kapatma, taze pozisyon/algo, eski veri veya saat geri hareketinde yeni heartbeat göndermez.

QUERY_CANCEL_TIMER yerel kayıt durumudur. Resmi sözleşmede uzaktan timer durumunu veren GET yoktur. Yerel beklenen bitiş saati borsanın devre dışı kaldığının kanıtı sayılmaz. Aktif, belirsiz, duraklatılmış veya başarısız timer durumunda yeni giriş engeli sürer. DISABLE_CANCEL_TIMER sıfır süre gönderip doğru ACK alınca engel kalkar. Önceki belirsiz isteğin kabul penceresi bitmeden sıfır süre gönderilmez; pencere sonrası yeni kapatma komutu gerekir. Kesin reddedilmiş ilk kurma, kurulu timer sayılmaz.

Giriş engeli V1/V2/SINGLE/GRID/NEUTRAL ve pozisyon artırma yollarına bağlandı. Veritabanı trigger'ı ham normal/algo giriş niyetlerini de engeller; azaltma ve kapatma emirlerini geçirir. Eski intents tablosunda hesap alanı bulunmadığından aynı veritabanındaki aynı sembol için engel muhafazakâr olarak ortaktır. Bu teslim bir execution hesabı başına journal kullanımını esas alır.
