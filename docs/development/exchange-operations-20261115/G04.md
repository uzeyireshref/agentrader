# G04 — Normal emir süresi, fiyat eşleme ve STP

16 Kasım 2026. **G04 yerel kabulü geçti: 1343 test, 107.194 saniye, OK.** Kapsam: mevcut demo Binance USD-M USDT perpetual SINGLE LIMIT girişi. Yeni seçenekler mevcut onay, sahiplik, ortak risk rezervi ve koruma yürütücüsünü kullanır. Kabul kaydı `reports/exchange-development-20261115/g04-validation.json` içindedir. Borsada finansal kabul işlemi yapılmadı.

## Kullanım ve sözleşme

V2 SINGLE LIMIT planının `entry` alanına isteğe bağlı `order_options` eklenir:

```json
{
  "order_options": {
    "time_in_force": "IOC",
    "self_trade_prevention_mode": "EXPIRE_BOTH"
  }
}
```

Bu parça tam plan değildir; mevcut miktar bütçesi, stop, hedefler, yetki ve kaldıraç alanları korunur. Destekli süreler GTC/IOC/FOK/GTX/GTD. Eski planda alan yoksa istek ve digest değiştirilmez, önceki GTC varsayılanı kalır. Yeni alanlar SINGLE LIMIT dışındaki girişte reddedilir; GRID ve NEUTRAL döngülerine sessizce uygulanmaz. GRID için GTC davranışı korunur.

GTD örneği `{"time_in_force":"GTD","good_till_date":1893456700999}` biçimindedir. Örnekteki tarihi kullanmak yerine amaçlanan UTC son geçerliliği milisaniye olarak belirtmek gerekir. Derleyici saniyeye aşağı yuvarlar; yuvarlanmış değer gönderim anından kesin olarak 600 saniyeden fazla ileride olmalıdır. GTD sonu gelmişken borsa emri hâlâ NEW döndürürse yönetim mevcut kimliği iptal eder ve terminal durumunu sorgular. Sadece saatin geçmesi terminal emir kanıtı sayılmaz. Planın daha erken sona ermesi/izin iptali önceki kurallarla girişi daha erken durdurabilir.

Fiyat eşleme için `price_match`: OPPONENT, OPPONENT_5/10/20, QUEUE, QUEUE_5/10/20. Planın `trigger_price` alanı onaylanan risk/fiyat referansıdır; borsaya gönderilen `price` değildir. price_match seçildiğinde derleyici `price` göndermez. Ortak düşük seviye doğrulayıcı aynı borsa isteğinde price ve priceMatch'i birlikte reddeder.

Fiyat eşleme sabit bir limit fiyat tavanı değildir. Borsanın seçtiği fiyat emir sorgusundan okunur. Bekleyen emirde onaylı referans toleransı/stop/ilk hedef aralığı dışındaysa kalan iptal edilir. Gerçekleşmiş miktar için eşlenen fiyat veya ortalama dolum fiyatı bu aralığın dışındaysa mevcut sahiplik kanıtıyla azaltma yönünde kapanış yapılır; bunun sonucu ayrıca uzlaştırılır. Bu kontrol borsa gerçekleşmesini önceden atomik olarak fiyatla sınırlandırmaz ve anlık fiyat riskini ortadan kaldırmaz.

Yeni STP seçimi yalnız EXPIRE_MAKER/EXPIRE_TAKER/EXPIRE_BOTH ve GTC/IOC/GTD birleşimlerini kabul eder. FOK/GTX ile etkisiz STP talimatı reddedilir. RPI ve yeni NONE seçimi sunulmaz. Sembol metadata'sı süre/STP uygunluk listesi içeriyorsa bu liste de uygulanır; liste yokluğu yeni bir özel hesap yetkisi varsayımı değildir. Borsa kesin ret verebilir, bu ret yeni POST ile aşılmaya çalışılmaz.

## Normal kullanıcı yolları

Mevcut `plans create/show/preflight/run` zinciri seçenekleri taşır. Ayrıca G03 genel CLI üzerinde **RUN_SINGLE_PLAN** işlemi eklendi. Bu bir strateji seçmez; kullanıcı tarafından zaten oluşturulmuş ve yetkilendirilmiş SINGLE yürütme kaydına bağlanır. Yeni onay veya risk muafiyeti üretmez.

```json
{
  "schema_version": 1,
  "client_command_id": "btc-ioc-001",
  "environment": "demo",
  "exchange": "binance",
  "product": "USD-M",
  "account_ref": "CONTEXT_CIKTISINDAKI_64_HANELI_HESAP_KAPSAMI",
  "operation": "RUN_SINGLE_PLAN",
  "scope": {"symbol": "BTCUSDT"},
  "parameters": {
    "plan_id": "yetkili-single-plan",
    "version": 1,
    "plan_digest": "PLANS_SHOW_CIKTISINDAKI_64_HANELI_DIGEST",
    "entry_options": {
      "time_in_force": "IOC",
      "self_trade_prevention_mode": "EXPIRE_BOTH"
    }
  }
}
```

account_ref `commands context`, plan_digest `plans show` çıktısından alınır. entry_options planın order_options değeriyle bire bir eşleşir; alanı olmayan eski planda `{}` verilir. Aynı veritabanı kullanılmalıdır.

```powershell
python -m agentrader commands prepare command.json
python -m agentrader commands show COMMAND_ID
python -m agentrader commands apply COMMAND_ID --digest DIGEST --execute-demo
python -m agentrader commands reconcile COMMAND_ID
```

Genel adaptör mevcut `RiskLimits()` varsayılanlarını kullanır. Özel risk profili gereken yürütme için mevcut `plans run --risk-profile ...` yolu korunur. Genel komuta serbest URL, serbest POST veya denetlenmeyen risk profili yolu eklenmedi. Hazırlama ağ isteği yapmaz. Aynı komut/aynı parametre süresini uzatmadan döner; farklı parametre reddedilir. Ayrı bir komut anahtarı aynı planın tek kullanımlık giriş hakkını çoğaltamaz.

## Dolum, rezerv ve kurtarma

HTTP ACK/RESULT içeriğinden dolum varsayılmaz; orijinal emir kimliği sorgulanır. Yanıt kaybında RUN_SINGLE_PLAN tekrar apply yeni giriş göndermez. Açık `commands reconcile` yalnız bağlı plan ve yerel emir günlüğünden sonuç gösterir. Borsayla uzlaştırma/koruma kurulması gerektiğinde mevcut `plans manage` yolu kullanılır. UNKNOWN otomatik tekrar gönderim izni değildir.

Sonuçta plan_state, entry_state, entry_outcome, filled_quantity, unfilled_quantity, reservation_state ve reserved_entry_quantity ayrı alanlardır. APPLIED, delege edilmiş yürütme sonucunun bilindiğini ifade eder; dolum veya pozisyon kapanışı garantisi değildir. FOK gerçekleşmeden EXPIRED olmuşsa NO_FILL ve CLOSED açıkça görünür. GTX kesin reddi, yönetim gönderimsiz/boş hesap kanıtını doğrulayana kadar korunur.

IOC kısmi dolumunda önce kalan girişin terminal olduğu, gerçek pozisyon sahipliği ve stop/hedef korumaları doğrulanır. Sonra yalnız gerçekleşmemiş SINGLE miktarının risk payı bırakılır. Tam ilk plan yetkisi ve rezerv digest'i değiştirilmez. Ek `single_reservation_caps` kaydı terminal miktar sınırını tutar; ortak portföy değerlendirmesi etkin miktarı kullanır. Geç gelen daha yüksek kümülatif dolum rezervi artırabilir; daha düşük gözlem azaltamaz. Bozuk kanıt yeni risk kullanımını engeller. Gerçekleşen pozisyonun rezervi yalnız doğrulanmış sıfır pozisyon ve terminal emirlerle bırakılır. GRID yeniden giriş bütçesi bu mekanizmayla azaltılmaz.
